# Not Bilbanan

A browser homage to *Bilbanan*, the Swedish slot-car Shockwave game from the early 2000s (once hosted on TV4 / Blip.se).

**Play:** https://www.alecsharpie.me/bilbanan/

- Drag track pieces from the top bar onto the board; drop them on the bin to remove them. Click a placed piece to rotate it.
- Close the loop through the start piece, then click the checkered flag (or press Enter).
- Hold **D** (red) or **K** / **Space** (orange), or hold a controller on screen. Too fast in a curve and you fly off.
- Click the cockatoo to race the computer; set its difficulty with **Nivå** 1–9.

Single file, no build step: everything lives in `index.html`.
